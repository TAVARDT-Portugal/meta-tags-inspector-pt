# Inspetor de Meta Tags e Protocolo Open Graph

[![Inspetor Meta Tags](https://img.shields.io/badge/TAVARDT-Meta%20Tags-5b3cf5.svg)](https://tools.tavardt.com/pt/verificador-meta-tags-seo/)

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Ferramenta automatizada de avaliacao de metadados HTML em Portugal, garantindo otimizacao de snippets de pesquisa e renderizacao de cartoes em redes sociais.

***

## Capacidades de Auditoria de Metadados e Redes Sociais

* **Análise de Titulo e Meta Descricao**: Avaliacao de limites de caracteres e contagem de palavras para exibicao limpa no Google e Bing.
* **Protocolo Open Graph**: Validacao estruturada de og:title, og:description, og:image, og:url e og:type.
* **Cartoes de Redes Sociais**: Conformidade com as diretivas Twitter Cards para partilha de conteudo.
* **Diretivas de Rastreadores**: Verificacao da etiqueta meta robots e presenca da ligacao canonica.
* **Indice de Qualidade de Metadados**: Avaliacao numerica de 0 a 100 com recomendacoes de otimizacao editorial.

***

## Instalação e Execucao

Requer Python 3.8 ou superior, utilizando exclusivamente a biblioteca padrao.

```bash
git clone https://github.com/TAVARDT-Portugal/meta-tags-inspector-pt.git
cd meta-tags-inspector-pt
python meta_inspector.py exemplo.pt
```

Para saída em formato JSON:

```bash
python meta_inspector.py exemplo.pt -json
```
